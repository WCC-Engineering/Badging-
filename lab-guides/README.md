# WCC Engineering Lab Guides

How-to guides for the 3D printer, laser cutter, and soldering stations in the WCC Engineering Lab.

**Live site:** https://cbolandedu.github.io/Badging-/

## Editing

All pages live in the `docs/` folder as Markdown (`.md`) files. Open one, click the pencil icon, make your change, and click **Commit changes**. The site rebuilds itself in about a minute. See `docs/contribute.md` for a quick Markdown guide.

## Folder map

- `docs/`: the pages
  - `3d-printing/`, `laser-cutting/`, `soldering/`: one folder per topic
  - `images/`: photos, one folder per topic
  - `downloads/`: slide decks
- `mkdocs.yml`: site settings and the menu order
- `.github/workflows/deploy.yml`: the robot that publishes the site
